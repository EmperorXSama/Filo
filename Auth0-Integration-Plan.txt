                    AUTH0 INTEGRATION PLAN — FILO
================================================================================

Auth0 Free Plan (2026): 7,000 active users, unlimited logins,
Universal Login, up to 2 applications, 1 database connection.

================================================================================
AUTH0 TENANT SETUP (one-time in Auth0 Dashboard)
================================================================================

Step 1 — Create Tenant
  - Go to https://manage.auth0.com → Create tenant
  - Name: filo-dev (or your preferred)
  - Region: closest to you
  - Plan: Free

Step 2 — Create Machine-to-Machine App (for user registration)
  - Applications → Create Application → "Machine to Machine"
  - Name: filo-api-management
  - Select "Auth0 Management API"
  - Scopes: create:users, delete:users, read:users, update:users
  - Copy: Client ID, Client Secret

Step 3 — Create Regular Web App (for BFF OIDC login)
  - Applications → Create Application → "Regular Web Application"
  - Name: filo-bff
  - Settings:
      Allowed Callback URLs: http://localhost:5005/api/auth/callback
      Allowed Logout URLs:   http://localhost:5005, http://localhost:5173
      Allowed Web Origins:   http://localhost:5173
  - Copy: Client ID, Client Secret

Step 4 — Create Database Connection
  - Authentication → Database → Create DB Connection
  - Name: Username-Password-Authentication (default)
  - "Requires username" = off
  - Applications tab → enable filo-bff

Step 5 — Note the Management API Audience
  - APIs → Auth0 Management API
  - Audience: https://{tenant}.us.auth0.com/api/v2/
    (used in token requests)

================================================================================
ROLLBACK / COMPENSATION PATTERN
================================================================================

  RegisterUserCommandHandler
    1. Auth0IdentityProviderService.RegisterUserAsync()
       → Auth0Client → POST /api/v2/users → returns auth0Id
       → if Auth0 fails → ErrorOr error returned
    2. compensationService.Register(...) → delete auth0 user if DB fails
    3. User.Create(auth0Id, fullName, email, Role.Member)
    4. userRepository.Insert(user)
    5. return userId

  UnitOfWorkBehavior (MediatR pipeline):
    → SaveChangesAsync() succeeds → commit
    → SaveChangesAsync() fails
      → compensationService.ExecuteAllAsync() → deletes Auth0 user
      → unitOfWork.RollbackAsync() → clears change tracker
      → return error response
